## Overview

Waves H-Reverb is a unique hybrid reverb combining FIR convolution with IIR feedback for detailed early reflections alongside evolving algorithmic tails in one innovative engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves H-Reverb** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Hybrid Engine** | FIR early reflections with IIR feedback tail for complete reverb response |
| **Time Stretch** | Stretch or compress the reverb tail without changing character |
| **Modulation** | Pitch modulation in the reverb tail prevents metallic resonances |
| **Envelope Shape** | Adjustable attack, hold, and decay shaping of the reverb envelope |
